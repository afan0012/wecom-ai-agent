# 排障手册

## 回调 URL 保存失败

依次检查：

1. DNS 的 A 记录是否已解析到正确公网 IP；
2. 80/443 是否在云防火墙放行；
3. `https://你的域名/healthz` 是否返回 `{"status":"ok"}`；
4. Caddy/Nginx 是否把请求转发到 FastAPI；
5. `WECOM_TOKEN`、`WECOM_ENCODING_AES_KEY`、`WECOM_CORP_ID` 是否与企业微信后台完全一致；
6. 查看 `journalctl -u wecom-ai-agent -f` 中的报错。

## 客户发消息后没有回复

- 确认事件勾选了“微信客服消息和事件”；
- 确认客服账号已授权给自建应用；
- 确认 `WECOM_KF_SECRET` 来自能管理该客服账号的应用；
- 查看后台是否有回调事件、服务日志是否出现 `处理微信客服文本`；
- 企业微信客服要求客户先主动发消息，企业才可在规定窗口内回复。

## 同一条消息被重复回复

不要删除 `data/wecom_state.db`。该数据库保存同步游标和已处理消息 ID；删除后服务会把下一次同步当作首次初始化，并跳过当批历史消息以避免重放。

## 回复过长或发送失败

企业微信客服文本单条最大 2048 UTF-8 字节，并且一个客户动作对应的可发送消息数有限。本项目会自动切分，仍建议在系统提示词中要求模型避免无必要的长篇回答。

## 模型不可用

- 检查 API Key、模型名和账户余额/额度；
- 检查服务器能否访问模型 API；
- 服务会退回安全的身份说明，不应暴露 Python 堆栈或密钥给客户；
- 不要把模型 API Key 放入前端、截图或 GitHub Issue。
