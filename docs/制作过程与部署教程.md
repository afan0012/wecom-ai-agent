# 从零搭建企业微信客服 AI Agent

这是一条可复现的路线：让外部用户通过微信客服链接或二维码，与一个由大模型驱动的 Agent 对话。

## 0. 先判断是否适合

适合：对外咨询、个人公开介绍、作品展示、常见问题、人工分流。

不适合：读取个人微信聊天记录、自动操作个人微信号、未告知地收集他人消息。若目标是企业内部员工助手，应优先使用企业微信官方“智能机器人”。

## 1. 准备清单

- 一个企业微信企业；
- 一个可创建微信客服账号的管理员权限；
- Ubuntu 服务器（起步建议 2 核、2 GB 内存、40 GB 磁盘）；
- 一个域名，例如 `bot.example.com`；
- 一个大模型 API Key；
- 一台可 SSH 登录服务器的电脑。

中国香港或海外服务器可以部署回调服务。若你需要中国大陆 ICP 备案，则应按云厂商要求另购中国大陆实例并走备案流程；这与企业微信回调本身是两件事。

## 2. 域名、HTTPS 与防火墙

1. 在 DNS 控制台添加 A 记录：`bot` 指向服务器公网 IPv4。
2. 在云防火墙放行 TCP 80、443；SSH 的 22 端口建议只允许你的固定公网 IP。
3. 将 [`deploy/Caddyfile`](../deploy/Caddyfile) 中的 `bot.example.com` 改成你的域名。
4. 安装 Caddy，让它把公网 HTTPS 转发到 `127.0.0.1:8000`。Caddy 会自动申请和续期证书。
5. 访问 `https://bot.example.com/healthz`。返回 JSON 后才继续配置企业微信。

## 3. 部署服务

```bash
sudo apt update
sudo apt install -y python3-venv caddy
sudo mkdir -p /opt/wecom-ai-agent
sudo chown "$USER":"$USER" /opt/wecom-ai-agent
git clone https://github.com/你的账号/wecom-ai-agent.git /opt/wecom-ai-agent
cd /opt/wecom-ai-agent
python3 -m venv .venv
.venv/bin/pip install -e .
cp .env.example .env
chmod 600 .env
```

填写 `.env` 后，复制 [`deploy/wecom-ai-agent.service`](../deploy/wecom-ai-agent.service) 到 `/etc/systemd/system/`，再执行：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now wecom-ai-agent
sudo systemctl status wecom-ai-agent
```

查看日志：

```bash
sudo journalctl -u wecom-ai-agent -f
```

## 4. 配置企业微信

按照 [企业微信后台配置](企业微信后台配置.md) 创建客服账号、自建应用并设置回调。回调地址填写：

```text
https://bot.example.com/webhooks/wecom/kf
```

企业微信保存时会立刻请求该地址进行校验。校验失败时，不要反复随机修改 Token；先按 [排障手册](排障手册.md) 检查 HTTPS、域名解析、Token、AESKey 与 CorpID。

## 5. 建立可审核知识库

把公开资料、FAQ 或作品说明先放入 `knowledge/drafts/`。人工审阅后再移动到 `knowledge/approved/`。

资料中必须明确写出：哪些内容可对外回答，哪些内容不能据此推断。机器人只读取已审核目录。

## 6. 验收

1. 新客户在微信客服中发送“你是谁”；
2. 客服后台与服务日志都确认只出现一次处理；
3. 连续发送一段长中文，确认会被切成可送达的多条消息；
4. 重启 systemd 服务，再发送新消息，确认旧消息没有被重放；
5. 询问未公开的价格、合作或私人信息，确认机器人要求本人确认。
