# 企业微信后台配置：微信客服 API

以下菜单名称可能随企业微信版本略有调整，以后台实际名称为准。

## 1. 创建客服账号

进入：**应用管理 → 微信客服**。

创建客服账号后，保存它的 `open_kfid`。该 ID 是后端发送消息时必须使用的客服账号标识。

## 2. 创建并授权自建应用

进入：**应用管理 → 自建 → 创建应用**。

为应用配置负责人，并在微信客服的“通过 API 管理会话消息”中，将需要管理的客服账号授权给这个应用。复制该应用用于微信客服的 Secret；不要把它发到聊天、截图或提交到 Git。

## 3. 设置 API 接收消息

进入目标自建应用的 **接收消息 → 设置 API 接收**，填写：

| 字段 | 填写内容 |
| --- | --- |
| URL | `https://你的域名/webhooks/wecom/kf` |
| Token | 自己生成的随机英文数字串 |
| EncodingAESKey | 点击平台的“随机获取”生成 |
| 事件 | 至少勾选“微信客服消息和事件” |

随后把 Token、EncodingAESKey、CorpID 和微信客服 Secret 填入服务器 `.env`。

## 4. 可信域名与可信 IP

如果后台提示需要配置可信域名或企业可信 IP：

- 可信域名填写回调域名，例如 `bot.example.com`，并按后台提示完成域名归属校验；
- 企业可信 IP 填服务器公网 IPv4；
- 这两项是企业微信调用接口与网页能力的权限控制，不等同于云防火墙。

## 5. 外部入口

客服账号详情页可复制接入链接或生成二维码。把它放在网页、名片、视频简介或海报中，用户即可在微信中发起客服会话。

## 6. 常见误区

- “微信客服”与“企业微信智能机器人”不同：前者面向外部微信客户，后者主要服务企业内部成员。
- 客服资料若已由自建应用 API 管理，应在该应用的配置范围内修改，不要依赖失效的原生机器人配置。
- 企业微信回调验证是服务端行为；浏览器能打开域名不代表验证一定能通过。
